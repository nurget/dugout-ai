# KBO 데이터 범위

## 화면에 표시하는 기록

타자·투수·전체 선수 메뉴는 같은 KBO 시즌 기록을 조회합니다. 시즌 기록지와 특정 경기의 기록지는 구분하며, 업데이트 시각은 적재된 스냅샷을 기준으로 표시합니다.

| 화면 | 조회 기준 | 표시 범위 |
|---|---|---|
| 선수 기록지 | KBO 타자·투수 시즌 기록 | 기본·추가 기록, 선수 구분, 원본에서 계산 가능한 지표 |
| 구단과 경기 | KBO 팀 기록·순위 | 승·패·무·승률, 타격·투구·수비·주루 |
| 경기 일정·기록지 | KBO 경기 일정과 경기별 투타 기록 | 선발·교체 타자, 타순, 투수 등판 기록 |
| 상대 타순 | 경기 기록지의 선발 명단 | 해당 경기 상대와 타순, 별도 시즌 성적, 기준일 이전 직접 맞대결 표본 |

현재 화면에서 제공하는 시즌은 2026년입니다. 타자 목록에는 투수가 가진 타격 기록도 존재하므로 기본 조회에서는 투수를 제외하고, 포함 옵션으로 확인합니다. 경기 기록지에 선수 ID가 없고 구단 내 동명이인이 있는 경우에는 선수 구분 미확인으로 표시하고 임의로 시즌 선수와 합치지 않습니다.

시즌 원문은 생성형 AI에 전달하지 않고, 정해진 산식의 계산과 기록 조회에 사용합니다. 직접 맞대결과 과거 기준일 집계는 별도 PBP 데이터의 제공 범위를 따릅니다.

## 현재 확보한 원본

| 데이터 | 시즌 | 범위 | 상태 |
|---|---:|---|---|
| PBP 투구 원본 | 2023–2026 | 경기·타석·투구 순서, 타자/투수 ID, 구종·구속·좌표, 투구 전후 상황, 타석 결과 등 배포 파일의 원본 컬럼 | 로컬 snapshot 및 DB 적재 완료. 2026 snapshot은 3월 28일–7월 26일 범위 |
| 완료 타석 PBP | 2023–2026 | 단일 타자·투수·결과가 확인된 타석 | DB 적재 완료. 미완료·혼합 투수 타석은 제외 |
| KBO 시즌 선수 기록 | 2026 정규시즌 | 타자·투수 기본·추가 기록, 선수 프로필 | 기록 메뉴의 공통 조회 기준 |
| KBO 구단 기록 | 2026 정규시즌 | 10개 구단의 순위·타격·투구·수비·주루 | 구단 기록 화면에서 조회 |
| KBO 일정·경기 기록지 | 2026 정규·포스트시즌 | 경기 결과, 타순, 타자·투수 경기 기록 | 일정과 상대 타순 화면에서 조회 |
| 경기별 투수 등판·부하 | 기존 기록 일부 | 경기별 등판 및 투구 수 등 | 제공 파일 범위에 한함 |

PBP snapshot은 `slothman3878/kbo_playbyplay` 배포자가 [데이터 카드](https://huggingface.co/datasets/slothman3878/kbo_playbyplay)에서 CC BY 4.0으로 표시한 자료입니다. 배포자는 Naver Sports 중계 API를 원천으로 설명하지만, 원천 제공자의 상업 이용·재배포 권리는 별도 검증하지 않았습니다. 저장소는 원본 데이터 파일을 공개 Git에 포함하지 않고, 각 파일의 revision, SHA-256, 출처 URL과 라이선스 표시를 sidecar manifest에 보존합니다. 공개 또는 상업 서비스에 사용하기 전에 권리 범위를 확인해야 합니다.

## 투구 원본 다운로드

파일이 로컬에 없을 때 시즌별로 실행합니다. 다운로드는 `data/private/`에 저장하며 DB는 변경하지 않습니다.

```bash
uv run python -m scripts.fetch_kbo_pbp_snapshot --season 2023
uv run python -m scripts.fetch_kbo_pbp_snapshot --season 2024
uv run python -m scripts.fetch_kbo_pbp_snapshot --season 2025
uv run python -m scripts.fetch_kbo_pbp_snapshot --season 2026
```

## DB 적재

DB에는 2023–2026 PBP 투구 805,960행과 완료 타석 206,354건이 적재되어 있습니다. 2026은 보유 snapshot의 종료일까지만 반영됩니다. `audit_kbo_pitch_events`로 DB 적재 행 수를 다시 확인할 수 있습니다. 마이그레이션 후 파일 검증 명령을 먼저 실행합니다. 기본 동작은 검증 전용입니다.

```bash
uv run alembic upgrade head
uv run python -m scripts.import_kbo_pitch_events data/private/kbo_pbp_2023.parquet --season 2023
```

품질 요약과 시즌 범위를 확인한 후 `--apply`를 추가하면 해당 시즌의 기존 `kbo_pitch_events` snapshot을 새 snapshot으로 원자적으로 교체합니다. 중복 투구는 하나만 유지하고, 같은 식별자에 서로 다른 값이 발견되면 적재를 중단합니다. 재실행 가능한 시즌 단위 작업이며 타석 요약 테이블에는 영향을 주지 않습니다.

```bash
uv run python -m scripts.import_kbo_pitch_events data/private/kbo_pbp_2023.parquet --season 2023 --apply
uv run python -m scripts.audit_kbo_pitch_events
```

다른 시즌도 같은 방식으로 실행합니다. 별도 PBP pitch table은 원천 행을 보존하며, 타석 결과가 없는 투구도 삭제하지 않습니다.

## PBP 파생 시즌 기록 조회

로그인 구단 범위에서 완료 타석 PBP를 사용해 기본 타자/투수 시즌 지표를 계산합니다. 적재된 원천 행을 재가공해 즉석 집계하며 공식 시즌 기록과 분리합니다.

```text
GET /api/teams/me/batters?season=2025&as_of_date=2025-06-30&name=김
GET /api/teams/me/pbp-pitchers?season=2025&as_of_date=2025-06-30&name=이
```

기준일은 제외하는 방식이며, 기준일 당일의 경기까지 포함하려면 다음 날짜를 기준일로 지정합니다. 타자는 PA, AB, H, 1B/2B/3B/HR, BB, SO, HBP, SF/SH, TB, AVG/OBP/SLG/OPS를 반환합니다. 투수는 단일 투수가 확인된 완료 타석으로 BF, 피안타, 피홈런, BB, SO, HBP, K%, BB%, K-BB%를 계산하고, 투구 원본에서 투구 수·구종 분포·구속 평균/최고를 계산합니다. 구속 평균은 구속이 제공된 투구만 포함합니다. 타점·득점, 투수 이닝/자책점/ERA/WHIP, 도루·수비는 계산하지 않습니다. 기준일 이전 성적 검색은 AI 에이전트 도구도 사용할 수 있으며 관련 질문에서만 도구 정의를 전달해 불필요한 입력 토큰을 줄입니다.

## 빠진 기록과 다음 확보 단계

선수 등록·말소, 부상·실시간 컨디션, 타구 추적 값은 현재 화면의 제공 범위에 포함하지 않습니다. wOBA·wRC+·WPA·RE24처럼 추가 가중치나 완전한 플레이 상태가 필요한 지표도 제공하지 않습니다. KBO 시즌 기록과 경기 기록지가 존재해도, PBP가 없는 기간의 직접 맞대결 표본을 복원한 것으로 간주하지 않습니다.

새 범위를 추가할 때는 시즌·대회·경기 범위, 갱신 시각, 결측과 중복, 선수 연결 상태를 확인합니다. 시즌 원문과 PBP 집계를 구분해 서로 다른 값의 기준을 설명합니다. 수집 코드와 원본 파일은 공개 Git에 포함하지 않습니다.
